# Todo List App 📝

A simple and modern Todo List application built with React and Vite. This project helps users organize their daily tasks and manage their productivity through a clean and responsive interface.

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 📋 Organize and manage daily tasks
- 📱 Responsive design for desktop and mobile
- 💾 Save tasks locally in the browser (if localStorage is implemented)

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Git and GitHub

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/smailsedrati00-afk/todo-list.git
```

### 2. Navigate to the project folder

```bash
cd todo-list
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to use the application.
